## 2. Purpose

This template supports a structured gap assessment against ISO/IEC 27001 Information Security Management System expectations. It helps identify current-state maturity, gaps, risks, remediation actions, ownership, and evidence required for audit readiness.

This template does not reproduce ISO/IEC 27001 requirements in full. It should be used alongside licensed copies of the relevant standard and organisation-specific risk and compliance requirements.

## 4. Rating Criteria

| Rating | Definition |
|---|---|
| Fully Implemented | Requirement is implemented, documented, operating effectively, and supported by evidence. |
| Partially Implemented | Requirement is partly implemented but lacks completeness, consistency, evidence, or operating effectiveness. |
| Not Implemented | Requirement has not been implemented or evidence is unavailable. |
| Not Applicable | Requirement is not applicable based on documented scope and justification. |

## 5. Priority Criteria

| Priority | Definition |
|---|---|
| High | Significant risk exposure, audit concern, regulatory concern, or control failure requiring urgent action. |
| Medium | Important gap requiring planned remediation within an agreed timeframe. |
| Low | Improvement opportunity or lower-risk gap that should be tracked and addressed. |
