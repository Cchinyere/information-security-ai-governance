## Purpose

The purpose of this repository is to provide structured, reusable resources for:

- Information security governance
- AI governance and responsible AI adoption
- ISO/IEC 27001 readiness and assurance
- ISO/IEC 42001 AI management system support
- NIST Cybersecurity Framework alignment
- SOC 2 readiness activities
- Gap assessments and control mappings
- Policy and procedure development
- AI risk classification and impact assessment

The repository is built for practical use by security, risk, compliance, audit, privacy, legal, technology, and business stakeholders.

## How to Use This Repository

1. Review the skill definition in `skills/information-security-ai-governance/skill.md`.
2. Use the templates in the `templates/` folder to structure assessments and readiness activities.
3. Review the example in `examples/` to understand how AI risk classification can be applied.
4. Use the framework overview in `docs/` to understand how ISO 27001, ISO 42001, NIST CSF, and SOC 2 relate to each other.
5. Adapt the templates to your organisation, project, client engagement, or portfolio scenario.

## Important Note

This repository provides educational and professional guidance. It does not replace formal legal advice, certification body requirements, independent audit judgement, or organisation-specific risk assessment.

Do not claim ISO certification, SOC 2 readiness, regulatory compliance, or audit success based only on these templates. Evidence, implementation, testing, governance approval, and independent validation are required.
