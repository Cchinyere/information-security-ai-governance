# ISO/IEC 27001 Compliance Checklist

## Purpose

This checklist supports a structured readiness review against ISO/IEC 27001 information security management system expectations.

It is intended for portfolio, internal gap assessment, audit preparation, and implementation planning purposes. It does not reproduce the ISO/IEC 27001 standard and should not be treated as certification advice.

---

## How to Use This Checklist

Suggested status values:

| Status | Meaning |
|---|---|
| Not Started | No documented activity or evidence exists. |
| In Progress | Some implementation exists, but it is incomplete. |
| Implemented | The requirement is documented, assigned, and operating. |
| Needs Improvement | The control exists but requires stronger evidence or maturity. |
| Not Applicable | The item does not apply and justification is documented. |
